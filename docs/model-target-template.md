# 直通率标准批量配置

入口：系统配置 → 机型指标配置 → 直通率标准配置。

## 模板下载

“下载模板”读取数据源全部订单中的机型，不限制年份、普通/L6 订单范围、
订单状态或看板的筛选条件。机型去重后与当前配置合并，历史手动配置也保留。
已配置标准使用当前编辑值，未配置机型填写 100。下载不会修改数据库。
数据源不可用时显示错误，不下载缺失机型的模板。
机型通过数据源 `GET /api/orders/models` 接口直接去重读取，
无需遍历订单分页，避免分页排序不稳定导致重复订单或机型遗漏。

模板为 Excel 文件，工作表名为“直通率标准”，两列表头为：

| 机型名称 | 直通率标准 (%) |
| --- | --- |
| 6210 C21 | 99.5 |
| 6210 C31 | 100 |

## 导入与保存

“导入模板”接受 `.xlsx`、`.xls` 文件，上限 10 MB、20,000 个机型。
可填写 `99.5`、`99.5%`，也可使用 Excel 百分比格式；纯数字 `0.5` 表示 0.5%。
空白标准按 100 处理，0 是有效配置。

整份文件校验通过后，按机型覆盖当前编辑列表中的同名标准并追加新机型；
文件未包含的已有配置保留。重复机型、空机型、非数字、超出 0–100 的标准、
公式单元格或不匹配的表头会阻止整份导入并显示错误行号，不应用部分数据。
导入仅修改编辑列表，点击弹窗的“保存配置”后统一生效。

列表支持搜索和每页 50 个机型，仍可手动添加、删除或编辑。
手动新增的默认值为 100；没有显式配置的机型，达标计算仍使用默认标准 100%。

## 接口

- `GET /api/settings/model-targets/models`：返回数据源全部机型名称。
  登录用户可访问，与既有机型指标配置权限一致，不额外要求 RTY 看板权限。
- 保存继续使用 `PUT /api/settings` 的 `modelTargets` 字段。
  统一设置接口在写入任何配置前验证所有机型名与标准数值。

本次不改变数据库配置结构，不自动覆盖当前已保存的标准。
