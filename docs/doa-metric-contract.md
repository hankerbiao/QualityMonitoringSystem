# DOA 指标口径

根据业务确认，销售订单看板的订单数量作为出货数量的代理值，不代表真实发货数量。

- 以 SCS 的 5000 公司且判定结果为“是”的申报为起点，按受理日期筛选。
- 使用销售订单号关联销售订单看板，纯数字订单号忽略前导零。未找到订单的申报不参与指标，并在看板和核对导出中列出。
- 匹配销售订单的多个生产订单行，订单数量相加；整个筛选范围内同一销售订单只计一次。
- 报修率 = 匹配申报的问题批次数量之和 / 匹配订单数量之和。
- 换件率使用同一分母；分子为服务单关联到未撤销的“换上”或“换上-up”换件记录的申报问题批次数量。
- 趋势按 SCS 受理日期分组，每个周期内销售订单去重。跨周期出现的订单在各周期分别计入，因此各周期分母之和可能大于整体分母。
- 客户或机型存在多个不同值时，该订单的对应维度归为未填写；按客户或机型筛选时不能将其归到某个具体值。
- 未匹配申报无法通过订单确定客户或机型，未匹配列表不受这两个维度筛选。
- 核对导出包含 SCS 申报原始字段及匹配状态、匹配订单看板行和订单来源字段、关联换件的网关流字段及计算说明。
