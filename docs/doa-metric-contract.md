# DOA 指标口径

销售订单看板的全部数据均属于 5000 公司。分母使用选定日期内符合筛选条件的销售订单计划数量，日期使用生产订单计划开始日期 GSTRS；该数量是出货数量的代理值，不是实际发货量。

- 分子取 SCS 5000 公司、判定结果为“是”且非待受理的记录，按其生产订单关联出的 GSTRS 筛选，累加问题批次数量。问题批次数量为空的记录不纳入统计；数量明确为 0 的记录保留。
- SCS 设备明细可能包含多个生产订单；每个订单必须匹配到唯一、有效的订单日期，且日期一致，才能计入对应日期。不能确定唯一日期的报修独立展示，不受日期筛选，不参与日期范围内的报修率。
- 关联通过去掉生产订单前导零后匹配销售订单数据；跨来源身份冲突、缺失订单或日期冲突不会猜测分配。SCS 同步编排在销售订单及 SCS DOA 完成后执行计划日期回填；旧数据需要先执行一次回填。订单后续发生变化时下一轮同步会重新计算。
- 客户通过 SCS 生产订单号关联订单看板取得；全部生产订单均匹配且客户唯一时才确定客户，订单缺失归入“未匹配客户”，客户缺失或冲突归入“未填写”。未提供生产订单时兼容按销售订单关联。筛选客户时，仅计入可确定归属的记录。
- 机型将 SCS 产品名称与订单数据中已知机型作不区分大小写的完整前缀匹配，选最长唯一匹配；无法确定时归入“未匹配机型”。订单计划数量按各生产订单行自身的机型汇总。
- 换件率使用同一分母；分子为服务单关联未撤销的“换上”或“换上-up”记录的报修问题批次数量。
- 到货明细展示分母订单行；报修明细展示纳入分子的记录，未匹配计划日期的报修可单独查询和导出。核对导出包括原始申报、分母订单来源数据及关联换件记录。
- 同一筛选条件的后端快照缓存两小时；浏览器当前标签页按用户及权限缓存看板和筛选选项，看板缓存不超过后端快照的到期时间。数据同步后，已缓存结果在到期前不会自动更新。
