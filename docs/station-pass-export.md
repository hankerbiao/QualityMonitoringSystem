# 工位过站直通率导出

右上角导出按钮输出三个 Sheet，按最近一次成功查询的条件读取数据：

| Sheet | 内容 |
| --- | --- |
| 工位直通率透视表 | 保留原有列、内容和格式，包括 RTY、组合工站及各工位直通率 |
| 销售订单 | 18 列原始订单字段，表头与 RTY 模板一致 |
| 维修故障明记录 | 34 列原始维修字段，表头与 RTY 模板一致 |

不再生成“汇总故障明细”页。两个新增 Sheet 第一行为表头；
无记录时也保留全部列，缺失值留空，数量 0 和标识前导零正常保留。
IF_l6 表头读取数据源 IF_L6。ZWXDT 仅按原始字段输出，
不使用 ZDATE_WX/ZTIME 拼接，不用 ZUSER 代填 U_FIX。

原始数据请求 `GET /api/rty/station-pass-export`，使用工位看板权限，
不要求 RTY 看板权限。接口接收 dateFrom、dateTo、serialNumber、
productModel、customer、base、orderScope，沿用 RTY 订单排除和复合机型绑定规则。
groupBy 仅控制前端透视表，不影响原始列。

订单按 GSTRS 选取，再关联所选订单的全部维修记录，不限制维修日期或维修年份。
复合机型包含绑定子件的维修，保留实际维修子件 SN，不改写源订单号。
同一 SN 的不同维修记录全部保留；只消除分批读取产生的同记录 ID 重复。
因此维修记录行数可能大于 RTY 故障台数。

原始数据由网关分页完整读取；查询失败或超过上限时不下载部分文件，
页面显示错误，按钮恢复后可重试。沿用单次 100,000 条订单、
250,000 条维修记录的上限。
