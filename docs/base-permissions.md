# 基地权限

入口：系统配置管理 → 用户管理 → 新建用户 / 编辑用户 → 可访问基地。

每个账号可选择“全部基地”或“指定基地”，指定模式支持多选。
一个基地都不选时，该账号没有基地数据权限；“全部基地”包含将来新增的基地。
权限适用于 RTY、工位直通率、LRR、关键工位影像追溯，以及这些页面的
搜索候选、汇总、明细、图片和导出。

管理员角色继续负责系统配置和用户管理，数据查询也遵守基地权限。
受限管理员只能管理基地范围不超出自己的账号，不能给自己或其他账号
授予更大的基地权限。内置管理员保持受保护。

历史账号缺少基地配置时按“全部基地”处理。后台每次请求从用户记录读取最新
权限，已有登录令牌立即受新权限限制；浏览器在重新聚焦窗口或定期刷新用户
资料后更新页面并清除旧页面状态。前后端缓存均按基地权限隔离。

## 存储和接口

- 用户记录及其 `profile` 中的 `basePermissions: null` 表示全部基地，
  `[]` 表示无基地权限，`["1000", "3000"]` 表示天津和昆山。
- 创建、编辑账号仍使用 `POST /api/admin/users`、`PATCH /api/admin/users/{username}`。
  编辑时省略 `basePermissions` 保留原配置，显式传 `null` 恢复全部基地。
- `GET /api/admin/base-options` 返回当前管理员可授予的基地。
- `GET /api/auth/me` 和登录响应包含基地权限。
- 基地中文名、生产编码及影像系统简称在后端统一转换，如天津 / 1000 / TJ。

没有填写基地筛选时查询所有已授权基地；主动提交未授权基地返回 403。
无法确定基地归属的数据对受限用户不可见。故障明细用生产订单确认基地归属，
LRR 在聚合前按生产订单基地过滤，避免相同物料跨基地累计。
受限用户访问图片时必须携带查询结果提供的 `photos[].accessToken`，
服务端校验图片路径、来源、有效期和当前基地权限。

现有全量数据源诊断接口不提供按基地隔离的数据，因此仅全部基地管理员可用。
